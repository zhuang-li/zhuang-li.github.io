## RMIT University

- **ISYS1079 / ISYS3476: Managing Semi-structured and Unstructured Data**
  **Role:** Sole lecturer and course coordinator. I designed the current curriculum and assessments, which cover data preprocessing, representation, retrieval, LLM workflows, and retrieval-augmented generation (RAG).

  For the 2026 offering, I built and operated one of the earliest centrally managed, course-wide LLM API services in RMIT's School of Computing Technologies. The service supports approximately 500 students with individual course keys, shared access to chat and embedding models, and usage controls for hands-on LLM workflow and RAG development and assessment.

- **COSC2502: C++ Programming Studio**
  **Role:** Lecturer. The course introduces programming practice and software development foundations using C++.
